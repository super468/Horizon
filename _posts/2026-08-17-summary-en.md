## [Show HN: DeepSeek V4 Flash Compressed to 56.8GB Runs on Mac](https://huggingface.co/steadfastgaze/DeepSeek-V4-Flash-0731-Coder-56.8GB-MoEspressoV2) ⭐️ 8.0/10

Developer "steadfastgaze" compressed DeepSeek V4 Flash (originally 284B total parameters, 13B active) to 56.8GB using IQ_K quantization and expert pruning, then successfully ran it on Apple Silicon to autonomously write a functional ARM64 C compiler with Fibonacci and FizzBuzz tests in under 1 hour. This demonstrates that frontier-level LLM capabilities can now run locally on consumer Apple Silicon hardware, potentially enabling private, offline AI coding assistants. The successful autonomous compilation task validates that significant compression can preserve complex reasoning and tool-use capabilities. The compression achieved 80B parameter reduction via REAP expert pruning while balancing IQ1_S_R4 (~1.5 bits/weight) with selective promotion to IQ2_KS/K for projections. A key challenge was preserving reasoning capabilities—the model initially produced thousands of tokens of looping thought before calibration with tool-calling traces fixed this.

rss · Hacker News - OpenAI / Anthropic / Gemini / DeepSeek · Aug 16, 17:13

**Background**: DeepSeek V4 Flash is a Mixture of Experts (MoE) model with 284B total parameters and 13B activated parameters, supporting 1M token context. MoE architecture uses routing networks to activate only relevant "experts" for each input, enabling massive scale with reduced computation. Apple Silicon (M-series chips) uses ARM64 architecture, and the mlx-iqk library provides efficient quantization for MLX-based inference on Metal.

## [Cloudflare Silently Injects Analytics When Switching Nameservers](https://news.ycombinator.com/item?id=49322107) ⭐️ 7.0/10

A developer discovered that Cloudflare silently injected a JavaScript analytics snippet (beacon.min.js from static.cloudflareinsights.com) into their HTML-only, JavaScript-free site (textlog.cc) after switching nameservers to enable R2 bucket serving. The analytics was enabled by default, requiring manual opt-out through the Analytics dashboard. This raises significant privacy concerns as users are automatically enrolled in analytics tracking without explicit consent, violating privacy-by-design principles. Users expecting only DNS services may unknowingly have tracking scripts injected into their sites, affecting both site operators and their visitors. The injected script is loaded from https://static.cloudflareinsights.com/beacon.min.js with a specific token tied to the site. Users can block it using Content Security Policy (CSP) headers or by ensuring their domain is set to DNS-only mode rather than proxied through Cloudflare. The issue specifically occurs when using Cloudflare as a proxy.

hackernews · Hacker News - OpenAI / Anthropic / Gemini / DeepSeek · Aug 16, 17:49

**Background**: Cloudflare offers a range of services beyond basic DNS, including CDN caching, SSL termination, and object storage (R2). When users point their nameservers to Cloudflare and enable proxying, Cloudflare can modify the HTTP traffic passing through its network. Web Analytics is a free product that provides website performance insights but operates on an opt-out model by default.

## [Qwen 3.8 27B Review: Excellent Model but Defaults to Overthinking](https://simonwillison.net/2026/Aug/16/qwen-38-27b/) ⭐️ 7.0/10

Simon Willison reviewed Qwen 3.8 27B, an Apache 2 licensed 27B parameter vision-capable LLM from Alibaba's Qwen research lab. The model shows impressive self-reported benchmarks outperforming both Qwen 3.6 27B and the closed-weight Qwen 3.7-Plus. The 27B parameter size is excellent for running on reasonably specced laptops, making advanced AI capabilities accessible without cloud dependency. Combined with Apache 2 licensing and strong self-reported benchmarks, this model offers developers a rare combination of capability, flexibility, and local deployment potential. The model defaults to 'xhigh' reasoning effort, which causes excessive thinking even on simple tasks - Willison found it used 22,276 reasoning tokens to produce 3,223 output tokens for a simple SVG generation task that took 21 minutes. The default 8,192 token context limit is insufficient; users need to increase it to the full 262,144 tokens.

rss · Simon Willison · Aug 16, 22:00

**Background**: Qwen is Alibaba Cloud's large language model family. Vision-language models (VLMs) are multimodal models that can process both images and text inputs to generate text outputs. The 27B parameter size is considered practical for local deployment as it can run on consumer hardware with sufficient RAM. Apache 2 licensing allows commercial use, modification, and redistribution.
