## [ChainDrop 蠕虫攻陷 1300 多个 npm 包](https://www.bleepingcomputer.com/news/security/massive-chaindrop-npm-supply-chain-attack-infects-hundreds-of-packages/) ⭐️ 9.0/10

一个名为 ChainDrop 的自我传播蠕虫已攻陷超过 1300 个 npm 包,这些包每月下载量达 20 亿次,包括热门缓存库 Keyv 和 Cacheable。攻击始于攻破 Keyv 维护者的 GitHub 账户,并通过合法的 GitHub Actions 工作流传播。 这次攻击代表了 npm 生态系统威胁的重大升级,因为它结合了凭证窃取和通过可信基础设施的自我传播功能。由于每月下载量达 20 亿次,潜在影响范围波及无数开发者和组织,其系统可能已被攻陷。 恶意包包含 setup.mjs 投放器和 Math_Symbol.js 窃密脚本,这些脚本在 npm install 期间自动运行,窃取 GitHub、npm、AWS 和 Kubernetes 的凭证。安研人员建议将安装过受影响版本的任何系统视为已被攻陷,重建环境、轮换所有令牌,并将 npm-cache[.]com 作为失陷指标进行监控。

telegram · zaihuapd · Aug 5, 03:04

**背景**: npm 是最大的 JavaScript 包仓库,Keyv 是一个广泛使用的简单键值存储库,支持多种后端。npm 上的供应链攻击越来越常见,攻击者通过攻陷维护者账户将恶意代码注入流行包中,然后传播到依赖项目。
