Attackers can exploit this by sending crafted GET requests (e.g., /dashboard../data/config.yaml) to read arbitrary configuration files and obtain JWT secret keys. This vulnerability is critical because it allows unauthenticated remote attackers to read sensitive configuration files containing JWT secret keys, potentially leading to full system compromise. With CVSS 9.1, it poses an immediate security risk to all Nezha Monitoring deployments that have not yet upgraded to version 2.0.13 or later. The vulnerability exists in the fallbackToFrontend component and can be exploited without any authentication. Attackers only need to craft malicious GET requests with path traversal sequences to access files outside the intended web root directory. The specific attack vector uses '../' to navigate to protected directories like /data/config.yaml.

It supports system status monitoring, HTTP/TCP/Ping checks, alarms, scheduled tasks, and online terminal functionality. The tool identifies admins through OAuth2.0 and grants them access to the management backend and all monitored nodes. This vulnerability was published on June 12 and affects all versions prior to 2.0.13.

This debate matters because it directly impacts how developers architect authentication systems. Misusing JWTs in browser sessions can lead to security vulnerabilities, while proper use in service-to-service scenarios remains secure and efficient. Key security concerns include the 'alg:none' vulnerability, token revocation difficulties, and long token lifetimes. Experts suggest using short-lived tokens (5-15 minutes) with refresh mechanisms and proper RSA/PPK signing methods to mitigate risks.

## [Custom PRNG in Slay the Spire 2 Ensures Cross-Platform Seed Consistency](https://tck.mn/blog/correlated-randomness-sts2/) ⭐️ 7.0/10

The developers of Slay the Spire 2 implemented a custom pseudo-random number generator (PRNG) in the game's codebase instead of relying on the C# standard library, ensuring that game seeds produce identical results across all platforms including desktop and mobile versions. This matters because the original Slay the Spire had a critical issue where seeds generated different outcomes on desktop versus mobile platforms due to differing standard library PRNG implementations. Instead of using large encoder networks to translate images and audio into text-compatible embeddings, Gemma 4 12B uses lightweight linear layers that project raw data directly into the LLM's hidden dimension space. All visual and audio reasoning then occurs within the LLM itself.
