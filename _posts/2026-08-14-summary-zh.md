## [NP 完全性在实践中是否被高估了？](https://gruhn.me/blog/2026-08-13/) ⭐️ 7.0/10

一篇题为《NP-Overrated》的博客文章对 NP 完全性理论的实践相关性提出了挑战，认为现实世界的软件系统通过设计选择而非算法方案来避免 NP 难问题。 这一讨论意义重大，因为它将理论计算机科学与实践软件工程联系起来，质疑最坏情况下的理论复杂度是否应该指导日常开发决策。 评论者指出，依赖管理器和类型系统通常通过设计约束完全消除 NP 难问题空间，而且实际的问题实例很少触发理论分析所预测的指数级爆炸式增长。

hackernews · theanonymousone · Aug 13, 20:14

**背景**: NP 完全性是一个复杂度理论概念，描述了与 NP 中任何问题“一样难”的问题——解可以快速验证，但目前没有已知的高效算法能够在所有实例中找到解。NP 难问题至少和 NP 完全问题一样难，最坏情况下的求解时间随输入规模快速增长。在实践中，许多 NP 难问题都有启发式算法或近似算法，在典型输入上效果良好。

Google 发布了 Gemini 3.6 Flash，新模型较 Gemini 3.5 Flash 减少了 17%的输出 Token，并通过更少的推理步骤和工具调用完成多步任务。其代码生成、知识工作和计算机操作能力均有提升，知识截止日期更新至 2026 年 3 月。Google 同时宣布 Gemini 4 已启动预训练。 Gemini 3.6 Flash 的 API 定价为每百万输入 Token 1.5 美元、每百万输出 Token 7.5 美元。该模型通过减少推理步骤和优化工具调用机制实现效率提升。Google 还推出了面向高吞吐、低延迟场景的 Gemini 3.5 Flash。

telegram · zaihuapd · Aug 13, 17:32

**背景**: Gemini 是 Google 的大型语言模型系列，旨在与 OpenAI 的 GPT 和 Anthropic 的 Claude 等模型竞争。Token 减少是指在保持响应质量的同时尽量减少生成的输出 Token 数量，这直接影响 API 成本，因为大多数提供商按 Token 收费。推理步骤是模型从输入生成输出所经历的计算过程，减少这些步骤可以提高效率。
