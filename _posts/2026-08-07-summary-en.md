## [Chinese Scientists First Confirm Existence of Glueballs](https://mp.weixin.qq.com/s/pvyNR1lN7QPx3IrpB3WtUg) ⭐️ 9.0/10

Chinese scientists leading the BESIII experiment have for the first time experimentally confirmed the existence of glueballs, a new form of matter predicted by the Standard Model composed of gluons bound together, after 15 years of research. The team discovered particle X(2370) in 2011 and in 2024 confirmed its quantum state properties are consistent with glueball characteristics. This is significant because glueballs have been sought for nearly 50 years as a key prediction of quantum chromodynamics. The discovery provides the most definitive experimental evidence of glueballs, validating the Standard Model's description of the strong nuclear force and confirming a fundamental theoretical prediction. The research team measured X(2370)'s spin-parity quantum number as 0⁺⁻, consistent with the theoretically predicted lightest pseudoscalar glueball. They also discovered multiple new decay modes and determined its "flavor singlet" property, confirming the particle's primary component is indeed a glueball.

**Background**: A glueball is a hypothetical composite particle composed entirely of gluons, the force-carrying particles that transmit the strong nuclear force and bind quarks together. Glueballs are a key prediction of quantum chromodynamics (QCD), the theory describing the strong interaction. The BESIII detector at the Beijing Electron-Positron Collider (BEPCII) is a large通用 magnetic spectrometer weighing approximately 800 tons, used to observe and measure particles produced from electron-positron collisions.

## [Datasette Patches SQL Injection Vulnerability in Mixed Public/Private Tables](https://github.com/simonw/datasette/releases/tag/1.0a38) ⭐️ 7.0/10

Datasette released version 1.0a38 (also backported to stable version 0.65.3) fixing a SQL injection vulnerability that affects instances serving a mixture of public and private tables in the same database. The vulnerability allowed users with access to any public table to bypass restrictions and execute SQL injection attacks to gain read-only access to private tables. This is a significant security issue because it could allow unauthorized read access to private data in configurations where public and private tables coexist in the same database using Datasette's permissions system. Administrators serving private tables in this manner should take immediate action. The vulnerability specifically affects Datasette instances with the execute-sql permission enabled on databases containing both public and private tables. Site administrators are advised to disable the execute-sql permission on affected databases as a precautionary measure. The original author noted this particular configuration (private and public tables in the same database) is likely rare.

github · simonw · Aug 6, 18:24

**Background**: Datasette is an open source tool for exploring and publishing data as interactive websites and APIs. It includes a permissions system that allows administrators to configure which tables are public or private. The execute-sql permission controls whether users can execute custom SQL queries against the database. SQL injection is a code injection technique that exploits security vulnerabilities in an application's database layer, allowing attackers to interfere with queries and access unauthorized data.
