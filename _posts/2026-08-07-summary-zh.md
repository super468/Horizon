## [中国科学家首次证实胶球存在](https://mp.weixin.qq.com/s/pvyNR1lN7QPx3IrpB3WtUg) ⭐️ 9.0/10

中国科学家领衔的北京谱仪 III 实验国际合作组历经 15 年研究，首次证实一类全新物质形态——胶球的存在。胶球由传递强相互作用的胶子相互吸引结合而成。研究团队于 2011 年发现新粒子 X(2370)，2024 年测得其量子态性质与胶球特性一致。 这一发现具有重要意义，因为胶球作为量子色动力学的重要预言，已被物理学家寻找了近五十年。这一发现提供了迄今为止最明确的胶球实验证据，验证了标准模型对强核力的描述，确认了一项基本理论预言。 研究团队测定 X(2370)的自旋宇称量子数为 0⁺⁻，与理论上预言的最轻赝标量胶球质量一致。研究还发现多个新衰变模式，并测定其"味单态"性质，证实 X(2370)的主要成分正是胶球。

**背景**: 胶球是一种假想中的复合粒子，仅由胶子组成，而不含任何价夸克。胶子是传递强核力并使夸克结合在一起的力载体粒子。胶球是描述强相互作用的量子色动力学（QCD）理论的重要预言。北京谱仪 III（BESIII）是北京正负电子对撞机上的大型通用磁谱仪，总重约 800 吨，用于观察和测量正负电子对撞产生的次级粒子。

## [Datasette 修复混合公共/私有表 SQL 注入漏洞](https://github.com/simonw/datasette/releases/tag/1.0a38) ⭐️ 7.0/10

Datasette 发布了 1.0a38 版本（同时回移植到稳定版 0.65.3），修复了一个 SQL 注入漏洞，该漏洞影响在同一数据库中混合提供公共表和私有表的实例。该漏洞允许拥有任何公共表访问权限的用户绕过限制，执行 SQL 注入攻击以获取对私有表的只读访问权限。 这是一个重要的安全问题，因为它可能允许在公共表和私有表共存于同一数据库并使用 Datasette 权限系统的配置中，进行未授权的私有数据读取。以这种方式提供私有表的管理员应立即采取行动。 该漏洞特别影响在包含公共表和私有表的数据库上启用了 execute-sql 权限的 Datasette 实例。建议站点管理员在受影响的数据库上禁用 execute-sql 权限作为预防措施。原始作者指出，这种特定配置（同一数据库中的私有表和公共表）可能很少见。

github · simonw · Aug 6, 18:24

**背景**: Datasette 是一个开源工具，用于将数据作为交互式网站和 API 进行探索和发布。它包含一个权限系统，允许管理员配置哪些表是公共的或私有的。execute-sql 权限控制用户是否可以针对数据库执行自定义 SQL 查询。SQL 注入是一种代码注入技术，利用应用程序数据库层的安全漏洞，允许攻击者干扰查询并访问未经授权的数据。
