## [Rosenbridge 硬件后门：VIA C3 处理器中的 x86 CPU 漏洞](https://github.com/xoreaxeaxeax/rosenbridge) ⭐️ 7.0/10

这一发现引发了对闭源 CPU 信任的根本性质疑，其影响延伸至 Intel ME 和 AMD PSP 等现代处理器。随着硬件复杂性增加且更多厂商生产缺乏文档的芯片，这一研究凸显了日益增长的硬件级漏洞风险。 该后门具体影响 VIA C3 嵌入式处理器，这是一款已有数十年历史的 x86 CPU 家族。研究人员提供了检测并可能禁用此漏洞的工具。安全社区对此是否真的是后门或未文档化的 CPU 功能存在争议。

hackernews · epestr · Aug 8, 07:04

**背景**: Rosenbridge 是一个研究项目，展示了某些 x86 CPU（主要是 VIA C3 处理器家族）中的硬件后门。VIA C3（Cyrix III）是一种用于嵌入式系统的 x86 兼容微处理器。在 x86 架构中，CPU 以不同的特权级别运行：ring 0 是具有完全系统访问权的内核模式，而 ring 3 是权限受限的用户模式。此后门允许 ring 3 代码跳转到 ring 0，绕过正常的特权升级保护。类似担忧也存在于 Intel 管理引擎（ME）和 AMD 平台安全处理器（PSP）——这些协处理器的运行权限甚至高于主 CPU，且用户无法禁用。
