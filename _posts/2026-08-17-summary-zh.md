## [Cloudflare 切换_nameservers 时静默注入分析脚本](https://news.ycombinator.com/item?id=49322107) ⭐️ 7.0/10

一位开发者在将_nameservers 切换到 Cloudflare 以启用 R2 存储桶服务后，发现 Cloudflare 静默地向其纯 HTML、无 JavaScript 的网站(textlog.cc)注入了 JavaScript 分析脚本(来自 static.cloudflareinsights.com 的 beacon.min.js)。分析功能默认启用，需要通过分析仪表板手动退出。 这引发了严重的隐私问题，因为用户在没有明确同意的情况下被自动加入分析跟踪，违反了隐私设计原则。仅使用 DNS 服务的用户可能在不知不觉中在其网站上注入了跟踪脚本，影响了网站运营者和访问者。 注入的脚本从 https://static.cloudflareinsights.com/beacon.min.js 加载，带有与网站关联的特定令牌。用户可以通过使用内容安全策略(CSP)标头或确保其域名设置为 DNS-only 模式而非通过 Cloudflare 代理来阻止它。该问题特别在使用 Cloudflare 作为代理时发生。

hackernews · Hacker News - OpenAI / Anthropic / Gemini / DeepSeek · Aug 16, 17:49

**背景**: Cloudflare 提供除基本 DNS 之外的多种服务，包括 CDN 缓存、SSL 终端和对象存储(R2)。当用户将_nameservers 指向 Cloudflare 并启用代理时，Cloudflare 可以修改通过其网络的 HTTP 流量。Web Analytics 是一款免费产品，可提供网站性能洞察，但默认采用 opt-out 模式运行。

## [Qwen 3.8 27B 评测：优秀模型但默认过度思考](https://simonwillison.net/2026/Aug/16/qwen-38-27b/) ⭐️ 7.0/10

Simon Willison 评测了阿里云通义千问实验室发布的 Qwen 3.8 27B，这是一款 Apache 2 许可的 270 亿参数视觉语言模型。该模型的自报基准测试显示其性能优于 Qwen 3.6 27B 和闭源的 Qwen 3.7-Plus。 270 亿参数规模非常适合在配置较好的笔记本电脑上运行，使高级 AI 能力摆脱云端依赖成为可能。结合 Apache 2 许可和强劲的自报基准测试，该模型为开发者提供了能力、灵活性和本地部署潜力的罕见组合。 该模型默认使用'xhigh'推理强度，导致即使在简单任务上也会过度思考——Willison 发现生成一个简单的 SVG 图像用了 22,276 个推理 token 来产生 3,223 个输出 token，耗时 21 分钟。默认的 8,192 个 token 上下文限制不够用，用户需要将其增加到完整的 262,144 个 token。

rss · Simon Willison · Aug 16, 22:00

**背景**: 通义千问（Qwen）是阿里云的大语言模型系列。视觉语言模型（VLM）是一种多模态模型，可以处理图像和文本输入并生成文本输出。270 亿参数规模被认为适合本地部署，因为它可以在内存充足消费级硬件上运行。Apache 2 许可允许商业使用、修改和再分发。

## [AI Coding 在金融科技 SDLC 中的落地实践：从代码生成到研发闭环](https://www.infoq.cn/article/LflwIiIVHRZlakxDgexC?utm_source=rss&utm_medium=article) ⭐️ 7.0/10

AICon 深圳的一场技术演讲分享了 AI 编码工具在金融科技软件开发生命周期中的落地实践经验，涵盖从代码生成到研发闭环的完整过程。 这一案例研究为金融科技等受监管行业的企业采用 AI 编码工具提供了宝贵的实施见解，这些行业严格的合规性和可靠性要求使得技术采用更具挑战性。该演讲涵盖完整的开发生命周期，为寻求从试点项目走向生产部署的组织提供了实践参考。 根据 InfoQ 上相关的 QCon 北京演讲，平安科技在高频迭代复杂业务系统中的 AI 编码试点实现了 60%的 AI 入库代码占比。他们采用"设计+规范"、"知识+工具"、"模式+流程"三大驱动方式，实现了 AI 模型能力增强与研发团队工程优化的双向提升。
