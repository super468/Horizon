## [RFC 10008：新型 HTTP QUERY 方法标准化](https://www.rfc-editor.org/info/rfc10008/) ⭐️ 8.0/10

IETF 已发布 RFC 10008，将新型 HTTP QUERY 方法标准化。该方法为需要请求体的请求提供了一种幂等的 GET 替代方案，解决了 HTTP 方法设计中长期存在的局限性——GET 历史上不支持请求体，而 POST 支持请求体但非幂等。 这使开发者能够在请求体中发送复杂查询参数（如 JSON 过滤结构或图像输入），同时保持幂等性，允许安全的自动重试。这将显著影响 API 设计、缓存策略，并可能使 HTML 表单避免使用 POST 时出现的烦人重新提交警告。 QUERY 请求目标以安全且幂等的方式处理所含内容并返回结果。与 POST 不同的是，QUERY 可以自动重复或重启，而无需担心部分状态变更。该方法是 HTTP 标准_track（Standards Track）的一部分。

hackernews · schappim · Jun 17, 10:51

**背景**: HTTP 方法如果多次相同请求的效果与单次请求相同，则被分类为幂等。GET、PUT、DELETE 是幂等的，而 POST 不是。HTTP 工作组此前曾考虑允许 GET 携带请求体，但由于历史互操作性问题及符合 HTTP 核心架构定义而拒绝该方案。RFC 编号现已达到 5 位数。
