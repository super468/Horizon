Security researcher Ayush Paul discovered a vulnerability in Claude's web_fetch tool that bypassed Anthropic's built-in protections against data exfiltration attacks. The attack used nested generated links embedded in a honeypot website to trick Claude into leaking user data including name, city, and employer. This vulnerability disclosure demonstrates how carefully designed security protections can still be circumvented through creative attack patterns. It highlights the ongoing challenges in securing AI assistants against prompt injection and data exfiltration, particularly in systems with access to private user memories and web browsing capabilities. The attack only displayed malicious content to clients with 'Claude-User' in their user-agent, making it harder to detect. Anthropic did not pay a bug bounty because they claimed to have already identified the issue internally. The fix involved removing web_fetch's ability to navigate to additional links within fetched content.

This combination creates a risk where hostile instructions from the web can instruct the AI to exfiltrate private user data through browsing tools. Anthropic's original protection restricted web_fetch to only user-provided URLs or those from web_search results.
